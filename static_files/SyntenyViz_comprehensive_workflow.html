1 Introduction

This vignette provides a comprehensive guide to using the SyntenyViz package for comparative genomics and synteny analysis. SyntenyViz is designed to visualize and analyze the conservation of gene order (synteny) across different biological species, facilitating evolutionary studies and comparative genomics research.

1.1 What You Will Learn

By the end of this vignette, you will be able to:

  • Set up coordinate ranges and convert them to genomic ranges
  • Extract and annotate genes from specific genomic regions
  • Create single and multi-species synteny plots
  • Search for orthologous genes across species
  • Calculate various similarity metrics (sequence, functional, evolutionary)
  • Analyze synteny conservation between species
  • Work with evolutionary and patristic distances
  • Integrate phylogenetic information into your analysis

1.2 Package Overview

SyntenyViz provides a comprehensive toolkit for synteny analysis with the following key capabilities:

  • Visualization: Create publication-ready synteny plots
  • Ortholog Analysis: Find and analyze orthologous genes
  • Similarity Metrics: Calculate multiple types of similarity scores
  • Evolutionary Analysis: Work with evolutionary distances and phylogenetic data
  • Multi-species Comparison: Compare synteny across multiple species simultaneously

# Calculate different types of similarity
if (!is.null(orthologs) && is.data.frame(orthologs) && nrow(orthologs) > 0) {

  })
  
  # Functional similarity
  cat("Calculating functional similarity...\n")
  tryCatch({
    func_similarity <- calculateOrthologSimilarity(orthologs, "human", "mouse", 
                                                  similarity_type = "functional")
  }, error = function(e) {
    cat("Error in functional similarity calculation:", e$message, "\n")
  })
  
  # Evolutionary similarity
  cat("Calculating evolutionary similarity...\n")

                                                 similarity_type = "evolutionary")
  }, error = function(e) {
    cat("Error in evolutionary similarity calculation:", e$message, "\n")
  })
  
  # Composite similarity (combines all types)
  cat("Calculating composite similarity...\n")
  tryCatch({
    composite_similarity <- calculateOrthologSimilarity(orthologs, "human", "mouse", 
                                                       similarity_type = "composite")

# Check if ape package is available for phylogenetic operations
if (requireNamespace("ape", quietly = TRUE)) {
  cat("Package 'ape' available - demonstrating phylogenetic tree operations...\n")
  
  library(ape)
  
  # Create a simple example tree
  tree_text <- "((human:0.0123,chimpanzee:0.0123):0.0111,gorilla:0.0234,orangutan:0.0456);"
  example_tree <- read.tree(text = tree_text)
  
  cat("Example phylogenetic tree created\n")
  
  # Calculate patristic distance from tree with error handling
  tryCatch({
    if (exists("calculatePatristicDistance")) {
      tree_distance <- calculatePatristicDistance(example_tree, "human", "gorilla")
      cat("Patristic distance from tree (human-gorilla):", tree_distance, "\n")
    } else {
      cat("calculatePatristicDistance function not available\n")
    }
  }, error = function(e) {
    cat("Error calculating patristic distance from tree:", e$message, "\n")
  })
  
  # Compare with stored distance
  if (!is.null(patristic_distances) && is.list(patristic_distances)) {
    stored_distance <- patristic_distances[["human-gorilla"]]
    if (!is.null(stored_distance)) {
      if (is.numeric(stored_distance)) {
        cat("Stored distance (human-gorilla):", stored_distance, "\n")
        if (exists("tree_distance")) {
          cat("Difference:", abs(tree_distance - stored_distance), "\n")
        }
      } else {
        cat("Stored distance (human-gorilla):", paste(stored_distance, collapse = ", "), "\n")
      }
    }
  }
  
  # Validate patristic distances against tree
  cat("\nValidating patristic distances against phylogenetic tree...\n")
  tryCatch({
    if (exists("validatePatristicDistances")) {
      validation_results <- validatePatristicDistances(example_tree, patristic_distances, tolerance = 0.01)
      if (is.data.frame(validation_results)) {
        cat("Validation results for", nrow(validation_results), "species pairs\n")
        if ("within_tolerance" %in% colnames(validation_results)) {
          cat("Pairs within tolerance:", sum(validation_results$within_tolerance), "\n")
        }
      } else {
        cat("Validation results:", paste(class(validation_results), collapse = ", "), "\n")
      }
    } else {
      cat("validatePatristicDistances function not available\n")
