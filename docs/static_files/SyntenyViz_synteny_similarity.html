SyntenyViz: Synteny similarity and evolutionary distances

knitr::opts_chunk$set(collapse = TRUE, comment = "#>")

Overview

This vignette demonstrates key capabilities introduced in recent versions:

  • calculateSyntenySimilarity(): compare syntenic regions across species
  • calculateOrthologSimilarity(): compute similarity metrics on discovered orthologs
  • Patristic/evolutionary utilities: getEvolutionaryDistances(), loadPatristicDistances(), calculatePatristicDistance(), and conversions between patristic distance and divergence time

Where examples might download annotations or require external data, chunks are marked with eval = FALSE.

Evolutionary and patristic distances

You can list available evolutionary distances and compute simple summaries.

evodf <- getEvolutionaryDistances()
head(evodf)
summary(evodf$evolutionary_distance)

Patristic distances and conversions:

pat_list <- loadPatristicDistances()
names(pat_list)[1:min(5, length(pat_list))]

# Convert between patristic distance and divergence time
d <- 0.3456
tmya <- patristicToDivergenceTime(d)
d_back <- divergenceTimeToPatristic(tmya)
c(d = d, tmya = tmya, d_back = d_back)
